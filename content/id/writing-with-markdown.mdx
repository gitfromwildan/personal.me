Tenang, ini gampang banget. Saya bantu. Mari kita bedah, dengan gaya santai.

## Dasar-dasarnya

Menulis di sini sama seperti menulis Markdown biasa, tapi dengan kekuatan super. Anda bisa menebalkan teks, *memiringkannya*, atau bahkan menambahkan blok kode seperti seorang pro.

```javascript:vibes.js
const mood = "chill";
console.log(`Current vibe: ${mood}`);
```

Tapi itu membosankan. Mari ke bagian yang seru.

## Komponen Kustom

Ada banyak komponen kustom yang bisa Anda pakai langsung di file MDX. Ini contekannya.

### Card
Ingin menautkan sesuatu dengan gaya? Pakai card. Mirip tombol, tapi lebih besar dan lebih berkarakter.

::::cards{cols="2"}
:::card{title="Github" icon="Github" href="https://github.com/gitfromwildan"}
Lihat karya open source saya.
:::

:::card{title="X" icon="Twitter" href="https://x.com/wildan_nrss"}
Ikuti saya untuk opini teknologi acak.
:::
::::

**Cara menulisnya:**
```mdx
::::cards{cols="2"}
:::card{title="Github" icon="Github" href="..."}
Lihat karya open source saya.
:::
// tulis card yang sama untuk X...
::::
```

### Accordion
Punya banyak teks tapi tidak ingin halamannya penuh? Sembunyikan di accordion. Cilukba!

::::accordions
:::accordion{title="Apakah ini sulit dipelajari?" icon="HelpCircle"}
Tidak! Sebenarnya sangat intuitif begitu Anda terbiasa.
:::

:::accordion{title="Bisa pakai ikon?" icon="Star"}
Tentu. Kami memakai ikon Lucide, jadi pilihannya banyak.
:::
::::

**Kodenya:**
```mdx
::::accordions
:::accordion{title="Pertanyaan?" icon="HelpCircle"}
Jawabannya di sini!
:::
// tulis accordion yang sama untuk Bisa pakai ikon?...
::::
```

### Tab
Cocok untuk menampilkan beberapa pilihan, seperti kode dalam bahasa berbeda atau beberapa langkah.

::::tabs
:::tab{title="npm"}
```bash
npm install @docubook/create@latest
```
:::

:::tab{title="pnpm"}
```bash
pnpm add @docubook/create@latest
```
:::

:::tab{title="bun"}
```bash
bun add @docubook/create@latest
```
:::
::::

### Stepper
Ingin memandu seseorang melewati sebuah proses? Komponen Stepper adalah sahabat Anda.

::::steps
:::step{title="Langkah 1: Rileks"}
Tarik napas dalam-dalam. Anda melakukannya dengan baik.
:::

:::step{title="Langkah 2: Tulis"}
Mulai saja mengetik. Jangan terlalu dipikirkan.
:::

:::step{title="Langkah 3: Terbitkan"}
Tekan tombol deploy dan bagikan ke dunia!
:::
::::
